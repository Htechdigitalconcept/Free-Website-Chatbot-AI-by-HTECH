How it works

The knowledge file is downloaded once and indexed in memory with BM25. Each question is scored against that index locally — typically in under 2 ms. Answers are sentences lifted from the business's own verified content, so nothing can be invented.

If you enable WebLLM in config.js, a small language model is downloaded to the visitor's browser cache and used to phrase those same verified facts more naturally. It still answers only from the retrieved text.

Deploying

htech/
├── config.js            ← your settings
├── knowledge.json       ← exported from WordPress
├── standalone.js        ← the widget
├── chatbot-widget.css
├── utils/
│   ├── retrieval.js
│   └── chunker.js
└── assets/
    ├── pdf.min.js       ← only needed for build.html
    ├── pdf.worker.min.js
    └── mammoth.browser.min.js

Copy the folder to your site and include the three tags. Works offline, on static hosts, and from a local file.
